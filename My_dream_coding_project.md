# My Dream Coding project:EcoTrack
## Project Overview 
**EcoTrack** is an app designed to help user *track their daily carbon footprint* and make small, sustainbale choices that add up to a big impact. Its built using **HTML, CSS**, and **JavaScript** - but one day, I want to expand it into a full web platform!
___
## Project Goals
- Build a user-friendly dashboard that tracks:

    - 🌿 Energy use
    - 🚗 Transportation impact
    - 🍔 Food consumption patterns
- Display personalized reports using:
    - `console.log()` to debug progress
```
if (carbonScore<50) {console.log("Great job staying eco-freidnly!");}{console.log("Let's find ways to reduce your footprint!");}
```
